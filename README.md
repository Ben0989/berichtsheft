# Fahrlehrer-Berichtsheft

Statische Web-App zur Dokumentation der Unterrichtseinheiten im Lehrpraktikum nach Anlage 3 FahrlAusbV.

- 1 UE = 45 Minuten
- Soll-/Ist-Auswertung für 330 UE
- Wochenkontrolle für 20 bis 32 UE
- Speicherung ausschließlich im lokalen Browserspeicher
- Druckansicht

Zum Starten `index.html` im Browser öffnen oder GitHub Pages für den Branch `main` aktivieren.

> Wichtig: Die Browserdaten werden nicht zwischen Geräten synchronisiert. Beim Löschen der Websitedaten können die Einträge verloren gehen.
